THREE MEALS IN YUNLIN – FOOD ADVENTURE RACE
Offline HTML5 classroom game

HOW TO RUN
1. Keep this whole folder together.
2. Double-click index.html in Chrome / Edge / Safari.
3. Choose Level 1 (Week 4) or Level 2 (Week 5).
4. Choose 2, 3, or 4 players and edit team names if desired.
5. Start the game and use the teacher buttons to judge spoken English.

CORE RULES
- Choose 2, 3, or 4 puppet tokens to race from START to FINISH.
- Roll → Move → Draw a flashcard → Speak.
- Correct: the same player gets ONE immediate bonus roll. A correct answer during that bonus roll does not create another bonus roll.
- Need help: teacher shows support; student repeats; turn ends. Never move backwards.
- Wrong: the player misses the next scheduled turn.
- REST: miss 1 turn.
- Night Market: say the Night Market sentence, then miss 1 turn because it is late.
- 3 correct answers in a row = Yunlin Star Boost (+1 space).
- FINISH requires an exact dice roll. If the roll is too high, the token stays in place and the turn ends.
- Star/Snack +1 boosts cannot move a token onto FINISH.
- Reaching FINISH opens a Final Meal Challenge: answer breakfast, lunch, and dinner questions.
- Correct Final Meal Challenge = win. Wrong = stay on FINISH and try again on the next eligible turn.

LEVELS
Level 1 / Week 4: food and meal sentences, including “I eat ___ for ___.” and Yunlin recommendation sentences.
Level 2 / Week 5: mini-dialogues using “What would you like for ___?” / “I would like some ___.” plus Week 4 review.

OPTIONAL FUN
- Surprise power-ups can be switched on/off.
- Funny speaking challenges can be switched on/off.
- Power-ups never make a student move backwards.

TEACHER SHORTCUTS
Space = Roll
C = Correct
W = Wrong
H = Need help
F = Fullscreen

TECHNICAL
- No internet required.
- No external libraries.
- No microphone or speech recognition: the teacher judges speaking, which is more reliable for a noisy low-EFL classroom.
- Game state is saved automatically in the browser so an accidental refresh can be resumed.


SOUND EFFECTS
-------------
This version uses lightweight Web Audio sound effects plus one compressed Jia-Jia voice audio file for dice rolls, cards, instructions, feedback, events and winning.
There is no background music. The single compressed voice file keeps loading light and avoids dozens of separate audio requests.
Sound effects can be switched off from Teacher controls.

JIA-JIA VOICE UPDATE
--------------------
- Jia-Jia voice is stored as ONE compressed audio sprite: assets/audio/jiajia-voice.mp3.
- Approximate audio size: 0.75 MB to keep web loading fast.
- Dice: the final number stays visible for 2 seconds and Jia-Jia announces the result before movement.
- Challenge cards: Jia-Jia announces the card and reads the question/instruction/sentence frame.
- CORRECT: Jia-Jia gives positive feedback. The same player gets one bonus roll only; bonus rolls do not chain.
- WRONG: Jia-Jia says the player misses the next scheduled turn.
- Help: relevant support/example audio is played. For Three Meals, the answer "Breakfast, lunch, and dinner" is reserved for help and is not revealed with the question.
- Special events: REST, Star Boost, Snack Boost, Lucky Dice, Rest Shield, Lucky Meal Pass, surprise and finish/winner messages use Jia-Jia's recording.
- New FINISH rule: exact roll is required, then Jia-Jia reads the three questions for the Final Meal Challenge.
- Funny speaking challenges also use Jia-Jia's recorded challenge voices and instructions.
