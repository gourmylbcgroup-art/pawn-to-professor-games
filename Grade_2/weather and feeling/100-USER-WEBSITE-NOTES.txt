WHAT WAS IMPROVED FOR ~100 USERS
- Removed the unused experimental MP3 voice sprite and service worker files.
- Replaced the old 40-audio-files-at-once startup burst with staged loading.
- Core classroom voice files preload first.
- Remaining voice files load quietly in the background.
- Maximum background audio loading concurrency is limited to 4.
- On the first user interaction, remaining audio is warmed in the background.
- If a requested voice has not loaded yet, it is loaded immediately and playback retries once.
- This reduces request spikes when many teachers open the activity at the same time.
