GRADE 2 UNIT 2 — STATIC WEBSITE OPTIMIZATION

Images converted to WebP, including lesson cards, presentation slides, index and soup characters.
Audio loads on demand instead of downloading at page load.
No external Google Font request in Soup Game.
All interactive logic remains client-side; no database request is needed for every answer.

DEPLOYMENT: Upload ALL extracted files and folders together. Do not upload the ZIP as a webpage.
Serve via HTTPS and a CDN (for example Cloudflare Pages or GitHub Pages with CDN).
Recommended HTTP headers: Cache-Control: public, max-age=31536000, immutable for versioned assets only; HTML and JS: Cache-Control: no-cache. If assets keep the same filenames across updates, use a shorter max-age or version their URLs.
For 100 concurrent visitors, capacity depends on your host, bandwidth, and device/network; this package alone cannot guarantee a load target.
Student progress is browser-local and does not synchronize between devices.

TEST: Run local server (python -m http.server 8000) and open http://localhost:8000; check all weeks, the soup game, audio and presentation before deployment.
