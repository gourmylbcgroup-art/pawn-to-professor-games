# Recommended static hosting cache rules
# HTML: short/no cache so updates appear quickly.
# MP3/WebP/PNG/JPG: long immutable cache when filenames are versioned.
#
# Vercel example:
# assets/* and Monster Mission.mp3 -> Cache-Control: public, max-age=86400, s-maxage=604800, stale-while-revalidate=2592000
