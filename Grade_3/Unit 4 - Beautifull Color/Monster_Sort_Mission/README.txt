MONSTER SORT MISSION — BIRD-SORT RULES UPDATE

Open: index.html

NEW CORE ORDER
1. Touch a TOP monster first.
2. Say the English answer.
3. Touch the destination platform.
4. The monster/group flies there if the move is legal.

BIRD-SORT MECHANICS
- Destination must be empty or have the same monster/color on top.
- Linked matching monsters at the top move together.
- Destination needs enough free spaces for the whole linked group.
- A completed group of 3 flies away automatically.
- Clear all six groups to win.
- Illegal moves do not move.
- Classic mode has no timer and includes Undo + Restart.
- Optional Team Race uses the same puzzle for each team; fastest time wins.

EFL
Level 1: What color is it? → It’s ___.
Level 2: How does the monster feel? → He is ___.
Level 3: Is it ___? → Yes, it is. / No, it isn’t.

Music and lyrics remain included.
