FAMILY MYSTERY HOUSE BATTLE V14 - TEACHER CODE SYSTEM

STUDENT GAME
1. Extract this ZIP.
2. Open index.html on the classroom computer or projector.
3. Press START and look for the CODE Sxx badge to the left of the question bar (never over the picture).
4. Teacher checks that code on a private device before choosing YES or NO.
5. On a wrong answer, the same team proceeds to the next door; on a correct answer, the next team gets a new picture.

PRIVATE TEACHER FILES
- teacher/Teacher_Answer_Key.html (standalone phone-friendly answer search; works offline)
- teacher/Teacher_Answers_Codes_Only.pdf (text-only printable code and answer sheet)
- teacher/answer_codes.csv and answer_codes.json (stable scene-code mappings)

Codes S01-S39 cover the 39 scenery mysteries, codes O01-O18 the original flashcards.
The mapping is fixed even though scenes are shuffled by the game.

FOR ONLINE HOSTING - IMPORTANT
Upload index.html plus assets/ and any existing deploy configuration files only.
DO NOT upload the teacher/ folder to a publicly accessible game host.
Instead, keep the teacher HTML/PDF on your phone or store behind genuine account authentication.
The codes on the student screen are identifiers, not access PINs. This static site does not implement secure server-side teacher authentication.
