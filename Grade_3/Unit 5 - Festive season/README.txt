PAWN TO PROFESSOR — GRADE 3 UNIT 5 — UPDATED
Festive Fun: Chinese New Year / New Year's Day / Compare

Open index.html locally or deploy index.html and the assets folder together.
On the homepage, choose LEVEL 1, LEVEL 2 or LEVEL 3 before selecting a lesson section.

LEVEL 1: Chinese New Year, family, red envelope, lion dance, dumplings, fish, rice cake, hot pot. Food sentence practice; speaking locked.
LEVEL 2: New Year's Day, January 1, countdown, fireworks, cake, pizza, fruit, juice. Party Table and food sentence practice; speaking locked.
LEVEL 3: Same / different / which celebration; listening classification, comparison sort and partner speaking mission.
GAME: four progressive Spot the Difference rounds: 3, 4, 5, 6 lesson-related differences, with gold circles and spoken clues.
PRESENTATION: 10 interactive built-in slides per level, 30 total. Original source ZIP did not contain an independent presentation slideshow; slides in this update are assembled using the existing content and approved assets plus text/emoji placeholders.
FLASHCARDS: Existing 50 image flashcards and existing organizer preserved. Some requested specific vocabulary pictures (fish, rice cake, hot pot, cake, pizza, fruit, juice, lion dance, January 1) were not present as approved image flashcards. These activities use text and emoji substitutes, not newly invented approved flashcard art. Supply approved images to replace these placeholders in a future update.

STORAGE: The viewer retains the existing PTPFlashcardStorage API, unit key grade3_unit5_new_year, localStorage fallback, max 3 sets, max 40 cards, ordered/hidden card persistence. If you have an authenticated existing shared ptp-flashcard-storage.js, include it alongside index.html; it is not in this ZIP. No new backend tables/routes/functions.

AUDIO: Uses browser speech synthesis (dependent on installed system voices). Music uses generated Web Audio.
OFFLINE: Main interface and images require no server. Cross-device cloud set sync requires the pre-existing account script and authentication.
IMAGE PROTECTION: Right-click and native dragging disabled; no claim of DRM.

AUDIT NOTES: JavaScript syntax and packaged asset paths checked automatically. Full browser interaction and authenticated cloud-storage end-to-end tests have not been completed in this environment.
