START — Number Flash

5 minutes • fast review in short chunks • no counting from 1

Round 1: Read together.
Teacher points → class reads.

Practice A — Find It

Hear or read a number. Tap the matching number. 7 calm rounds.

Practice B — Number Words

Match “one, two, three…” to the correct digit. 7 rounds.

Practice C — Pattern

Find the missing number in simple 1–10 patterns. 7 rounds.

Teacher script

1) “Look.” 2) Point to each number. Students read together. 3) Repeat in pairs. 4) Optional whisper round. Keep the pace predictable. If a student needs more time, repeat the same flash before moving on.
