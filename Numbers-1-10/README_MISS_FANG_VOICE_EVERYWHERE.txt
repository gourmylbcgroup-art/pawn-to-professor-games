MISS FANG VOICE — EVERYWHERE VERSION

This package keeps the original How Old Am I interaction and its two linked games.

VOICE COVERAGE
1. Main How Old Am I lesson: Miss Fang recorded audio engine added.
2. Number Rope Battle: Miss Fang speaks the numbers 0–10 and “Pull!”.
3. Call My Parent: Miss Fang recorded voice remains embedded.

IMPORTANT
- Browser/system TTS speaking has been removed from all three interactions.
- No SpeechSynthesisUtterance or speechSynthesis.speak calls remain.
- Audio is embedded in the HTML, so local and GitHub Pages use the same recordings.
- Dynamic lesson phrases are resolved using Miss Fang’s recorded phrases and number components. If a full dynamic sentence was not present in the recording, the lesson uses the closest recorded Miss Fang cue/number sequence; it never falls back to a computer voice.
