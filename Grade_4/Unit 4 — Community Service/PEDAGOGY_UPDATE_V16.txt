Quick Pick V16 — Progressive Support Update

LEARN
- Guided learning only: word + picture + full sentence + audio.

PRACTICE
- Students choose the correct answer.
- Wrong answer: Try Again; same item remains.
- Correct answer: full answer card pops up and full sentence audio plays.
- Week 3 uses full-sentence multiple-choice options.

PLAY
- Reduced support: picture + “Where is Grandpa/Grandma?” only.
- Object clue removed.
- Answer choices remain.

SPEAK
- No object clue.
- Sentence frame only, e.g. “Grandpa is ___ the sandbox.”
- Model answer remains teacher-controlled.

FINISH
- Minimal support: picture + question; no clue and no automatic prompt audio.

GAME / FINAL CHALLENGE
- No clue, no speaker/model prompt, all four prepositions mixed.
- Correct answer still gives feedback after the student answers.
