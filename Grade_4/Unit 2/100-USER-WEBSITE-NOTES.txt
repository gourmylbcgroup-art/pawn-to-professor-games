What Time Is It? — 100-User Website Optimization

SOUND
- All 156 original WAV files are preserved byte-for-byte.
- No voice file was removed.
- No voice file was compressed or re-encoded.
- Playback still uses the original local WAV files.
- The old version could warm more than 160 audio clips in a rapid burst.
- The 100-user version warms only common interface voice cues, spaced 180 ms apart.
- Time clips load only when actually needed, then remain cached in the browser.

WHY THIS HELPS
With 100 simultaneous users, downloading every time clip immediately would create thousands of
audio requests at once. This version avoids that startup spike while keeping all audio available.
