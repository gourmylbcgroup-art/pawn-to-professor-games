THREE MEALS IN YUNLIN – FOOD ADVENTURE RACE
Offline HTML5 classroom game

HOW TO RUN
1. Keep this whole folder together.
2. Double-click index.html in Chrome / Edge / Safari.
3. Choose Level 1 (Week 4) or Level 2 (Week 5).
4. Edit the four team names if desired.
5. Start the game and use the teacher buttons to judge spoken English.

CORE RULES
- Four puppet tokens race from START to FINISH.
- Roll → Move → Draw a flashcard → Speak.
- Correct: stay on the new space.
- Need help: teacher shows support; student repeats; turn ends. Never move backwards.
- Breakfast / Lunch / Dinner: correct challenge = play again.
- REST: miss 1 turn.
- Night Market: say the Night Market sentence, then miss 1 turn because it is late.
- 3 correct answers in a row = Yunlin Star Boost (+1 space).
- Exact roll is not required at FINISH.

LEVELS
Level 1 / Week 4: food and meal sentences, including “I eat ___ for ___.” and Yunlin recommendation sentences.
Level 2 / Week 5: mini-dialogues using “What would you like for ___?” / “I would like some ___.” plus Week 4 review.

OPTIONAL FUN
- Surprise power-ups can be switched on/off.
- Funny speaking challenges can be switched on/off.
- Power-ups never make a student move backwards.

TEACHER SHORTCUTS
Space = Roll
C = Correct
H = Need help
F = Fullscreen

TECHNICAL
- No internet required.
- No external libraries.
- No microphone or speech recognition: the teacher judges speaking, which is more reliable for a noisy low-EFL classroom.
- Game state is saved automatically in the browser so an accidental refresh can be resumed.


SOUND EFFECTS
-------------
This version uses lightweight Web Audio sound effects for dice rolls, token movement, correct answers, help, meal bonuses, power-ups, REST, Night Market and winning.
No MP3/WAV files are downloaded or streamed, and there is no background music. This keeps playback immediate and avoids online audio lag.
Sound effects can be switched off from Teacher controls.
